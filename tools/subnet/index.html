Kalkulator Subnet

Masukkan alamat IPv4 dan prefix, lalu lihat network, broadcast, dan rentang host yang bisa dipakai.

network
broadcast
subnet mask
wildcard
total alamat
host bisa dipakai
rentang host

Prefix /31 dan /32 dihitung sesuai RFC 3021: tidak ada network dan broadcast terpisah, jadi semua alamat bisa dipakai.

Dibuat pakai JavaScript tanpa library.
